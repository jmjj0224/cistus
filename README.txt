실행 방법 (맥)
1. start.command 를 더블클릭해요. 처음에 맥이 막으면 우클릭 → 열기를 눌러요.
2. 브라우저가 열리면 화면을 클릭해서 시작해요.
3. 끝낼 때는 터미널 창을 닫아요.
(index.html 을 그냥 더블클릭하면 열리지 않아요. 꼭 start.command 로 열어요.)

조작
WASD 이동 / 마우스 시점 / 마우스 왼쪽 버튼 누르고 있기 = 라이터 불 / Shift 달리기 / Esc 일시정지
자막이 남아 있어도 다음 매미에 불을 대면 자막이 바로 접혀요. 민트초코 장면은 클릭하면 넘어가요.

스마트폰
화면 왼쪽을 밀면 이동 / 화면 오른쪽을 밀면 시점 / 불 버튼을 누르고 있기 = 라이터 불
세로로 들고 있어도 화면이 가로로 돌아가서 나와요.

들어 있는 파일
- assets/audio/song_ending.mp3   엔딩 곡. 원곡의 2:04부터 끝까지만 잘라 둔 파일이에요.
- assets/video/clip_*.mp4        힉스필드로 만든 영상 4개. 지우면 코드로 만든 움직임이나 정지 그림이 대신 나와요.
- assets/album_cover.jpg         넣으면 엔딩 뒤 화면에 앨범 자켓이 나와요. (지금은 없어요)
- 곡 제목, 아티스트, 유튜브 링크는 src/config.js 의 song 항목에, 엔딩 크레딧은 src/script.js 의 CREDITS 에 있어요.
